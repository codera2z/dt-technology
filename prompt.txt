DT TECHNOLOGY — SESSION ENTRY

This is a start-up checklist, not a second project specification. The repository is the source of truth; do not keep a parallel assistant-memory copy of project facts or decisions.

## Start or resume
1. Read `AGENTS.md` and `HANDOFF.md` in full.
2. Read `DESIGN.md` for visual, content or interaction work.
3. Read `LICENCES.md` before adding or changing third-party assets/components.
4. Report the current branch and commit, HANDOFF version, phase and next step. If a file cannot be read, identify it; never guess.

Authority: latest owner instruction → AGENTS.md (standing rules) → HANDOFF.md (progress) → DESIGN.md (product specification) → LICENCES.md (asset records).

## Session commands
- `START` / `RESUME`: perform the start-up checklist and continue from HANDOFF.md. Do not repeat setup or completed phases.
- `CLOSE`: rewrite HANDOFF.md completely, retain its current headings, stay under 350 words and leave the edit unstaged/uncommitted for owner review.
